# Phase 16.3: Real-Time Graphics & Interactive Garment Design Engine

## 1. Mission & Integration Summary

Phase 16.3 upgrades YORVYN's garment viewing experience into a synchronized interactive 2D/3D garment design studio seamlessly anchored inside the Stylist chat workflow:
- **Stylist Garment Card Integration**: [GarmentJobMessage.tsx](file:///Users/anujsandhu/Projects/yorvyn/frontend/src/components/ai/GarmentJobMessage.tsx) exposes **Open Design Studio**, launching [GarmentDesignWorkspace.tsx](file:///Users/anujsandhu/Projects/yorvyn/frontend/src/components/design/GarmentDesignWorkspace.tsx) inside a top-level portal bound to the exact candidate GLB, `garment_id`, `category`, and Phase 16.2 construction patterns.
- **Interactive 3D Viewport**: [InteractiveGarment3DEditor.tsx](file:///Users/anujsandhu/Projects/yorvyn/frontend/src/components/design/InteractiveGarment3DEditor.tsx) + [RealtimeMeshEditor.ts](file:///Users/anujsandhu/Projects/yorvyn/frontend/src/engine/designStudio/RealtimeMeshEditor.ts) mutate Three.js `BufferGeometry` positions and normals in place from immutable rest buffers, support `THREE.Raycaster` component picking, inspect Wireframe/Normals/UV Grid/Panels/Seams/Bounds, switch camera and lighting presets, preview cloth sway/simulation modes, and monitor live FPS/draw-call/triangle telemetry.
- **Interactive 2D Pattern CAD**: [Pattern2DEditor.tsx](file:///Users/anujsandhu/Projects/yorvyn/frontend/src/components/design/Pattern2DEditor.tsx) edits CCW `PatternPiece2D` contours with 1 cm snapping, zoom/pan, seam allowance outlines, darts, notches, grainlines, and layer visibility.
- **2D <-> 3D Synchronization, Undo/Redo, Persistence & Exports**: [DesignStateEngine.ts](file:///Users/anujsandhu/Projects/yorvyn/frontend/src/engine/designStudio/DesignStateEngine.ts) synchronizes 2D vertex edits and 3D parametric deltas bidirectionally with compact undo/redo delta history, version-conflict detection (`409` on stale parent revisions), and multi-format export (`GLB` via rig-preserving [garment_design_routes.py](file:///Users/anujsandhu/Projects/yorvyn/backend/app/api/garment_design_routes.py) `candidate-edit-gl` + fallback client `GLTFExporter`, `GLTF`, `SVG`, `DXF`, and `Construction JSON`).
- **Avatar Fit Bridge**: **Wear on Avatar** produces an Ara3D-rigged binary `.glb` preserving bone weights and coordinates and passes it directly into [AvatarStudioViewer.tsx](file:///Users/anujsandhu/Projects/yorvyn/frontend/src/components/AvatarStudioViewer.tsx) (`GarmentAvatarFittingEngine`).
