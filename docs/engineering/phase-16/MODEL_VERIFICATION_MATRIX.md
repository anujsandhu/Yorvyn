The image-conditioned reconstruction engine, `pattern_construction_engine` (Phase 16.2 deterministic construction & 2D computational geometry engine), and category builders are software engines rather than learned neural weights. Their receipts record the engine identity, pattern piece/seam validation outcomes, and explicit evidence vs inference states (`OBSERVED` / `INFERRED` / `UNSUPPORTED`). The separate legacy specialized garment heads have partial compatibility. The original Phase 13 v3 artifact was unavailable for historical recertification. The Phase 15.5 certification report documents the release chain and the distinction between v3 compatibility bytes and v6.

Generic CLIP, optional open-weight image adapters and deterministic analytical stages are recorded by the local perception service. A cache check indicates availability only. Groq, OpenRouter and Gemini use independent credentials, capabilities and upstream identities. The last credentialed acceptance run recorded HTTP 401 for Groq/OpenRouter and HTTP 403 for Gemini. Phase 16.1–16.3 local runs exercise `human_parsing_segformer_b2`, `clip_vit_b32_local`, deterministic 2D pattern construction, and Three.js WebGL2 real-time interactive geometry/material editing (with `navigator.gpu` WebGPU probing gated to WebGL2 production rendering) without adding external API certification or independent sewing/physical accuracy claims. Phase 16.3.1 adds semantic 2D-to-3D correspondence verification, scoped dimensional reconciliation, extended construction DAG/symmetry/allowance checks, and atomic revision transactions without modifying upstream model weights or claiming physical tailor accuracy. Phase 16.9 MotionCore coordinates Three.js single-mixer skeletal animation, Ara & Mixamo bone retargeting, bounded IK/Pose adapters, XPBD garment sync + `three-mesh-bvh`, secondary motion, estimated material profiles (`is_measured_physical=False`), and animated glTF v2 validation without webcam dependency or physical tailor accuracy claims. Phase 17.0 YIP extends `UnifiedModelRegistry` with local HF cache SHA-256 verification (`dinov2_small` live MPS execution verified P50 `32.29 ms`, `universal-garment-classifier` v6 P50 `21.06 ms`), marks `fashion_clip_native` and `siglip_native` explicitly `UNAVAILABLE`, adds hybrid dense+BM25+trigram RAG (`pg_trgm 1.6` available, `pgvector` absent), independent multi-domain critic (`IndependentQualityCritic`), bounded candidate optimizer (`ControlledCandidateOptimizer`), and offline dataset curation/PyTorch probe harness (`promoted_to_production=False`).
