# Routing decisions

| Condition | Decision and execution |
| --- | --- |
| Recognized ordinary instruction | Execute local rules. Upload identification, reconstruction, bounded editing, undo, inspection and job control share the existing action vocabulary. |
| Ambiguous phrasing with a garment context | A supplemental planner may return one schema-validated action. Failed attempts retain sanitized reason codes. Unsupported, negated or compound changes can require clarification. |
| No garment evidence, multiple matching subjects or unresolved identity conflict | Request more evidence. Display a garment selection or front-view request. Do not submit a geometry job. |
| Verified classifier resident on CPU or MPS | Run v6 on the selected RGB image. Validate both output distributions and retain its checkpoint identity. Simple category identification can finish here. |
| Rich construction details required or classifier uncertain/unavailable | Consult available local component/perception analysis. Use v6 category confidence on agreement. A confident cross-model disagreement blocks reconstruction. If no adequate local category evidence is available, ask for another view. |
| Reconstruction with usable front evidence | Verify V2 integrity and re-hash the uploaded sources. Use the local image-conditioned route for upper-body garments including denim jackets and hoodies. Use the category-specific parametric registry for bottoms, dresses, skirts, footwear and accessories. Additional rear and side views enter existing fusion stages. |
| Candidate edit or undo | Re-open the authorized source, replay only approved edits, check the resulting GLB and bind the parent turn and checksum. Older records use their saved edit lists. |
| Repeated failed reconstruction | Following two failed retries, require further evidence before retrying. An interrupted worker retains its own deadline and state. |
| Credentialed acceptance run | The disposable staging harness explicitly requires upstream receipts. This server-controlled switch is distinct from normal Stylist policy. |

The category policy uses a 0.65 threshold for standalone classifier evidence and a 0.50 floor for fused reconstruction identity. These are operational abstention thresholds. There is no deployment-specific held-out calibration establishing either as an accuracy guarantee. Geometry, material and fit gates use their own evidence. Supplying a confident category cannot satisfy them.

The cost preference is discrete. Local rules avoid an external request, a sufficient single classification avoids the heavier component stack, and rich garment tasks reuse the existing local pipeline. Explicit input, model, hardware and quality gates precede selection. No per-model dollar or latency ranking has been learned. Historical certification informs eligibility. Historical quality estimates without suitable references cannot override an abstention.

To add an operation, declare its capability, bind a trusted implementation and validator, specify a deadline and pass a versioned parameter contract. Add success, refusal and provenance coverage before certifying it. The catalog differentiates browser/worker capabilities from the server operations that are callable directly.
